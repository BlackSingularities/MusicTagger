## 1.3.0

- Zgłaszanie błędów i sugestii: nowa pozycja „Zgłoś błąd lub sugestię” – opis trafia prosto do autora przez redzikowski.com, e-mail jest opcjonalny.

## 1.2.8

- Android: updates are downloaded inside the app (with progress) and installed through the system package installer – no browser, clear error messages, and the update continues by itself after allowing app installs.

## 1.2.7

- Android: minimalist start screen – title, a single "Open folder" button and plain lists instead of large tiles.

## 1.2.6

- No mention of GitHub anywhere in the app: new update server address, error messages without third-party host names.

## 1.2.5

- The update prompt only says that a new version is available – no change list, links or download source.

## 1.2.4 — Installer only

- Windows is now released only as the setup installer; MSI and portable builds are gone. Portable copies update by running the installer.
- Installer fully translated into Polish (no more empty labels).
- Install for the current user or, with administrator rights, for all users; updates reuse the previous install location.
- Android: bottom tab bar in the style of OpenCalc.

## 1.2.3 — Refreshed icon background

- Warm cream-to-peach background behind the application mark on Android (adaptive, legacy and round), Windows, macOS and iOS icons.
- Android launchers no longer show a black tile behind the transparent icon.
